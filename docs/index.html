Story Reader

Đọc truyện · TTS · auto-scroll · dịch chữ — dùng bằng bookmark trên điện thoại (Chrome / Safari) không cần cài extension hay Kiwi.

1. Kéo bookmark (máy tính)

Kéo nút dưới đây lên thanh Bookmark của trình duyệt:

📖 Story Reader

Rồi mở trang chương truyện → bấm bookmark đó.

2. Điện thoại (Chrome / Safari)

  1. Copy toàn bộ dòng javascript:… trong hộp bên dưới.
  2. Bookmark trang này (★ / Share → Bookmark).
  3. Vào danh sách bookmark → Sửa bookmark vừa tạo.
  4. Xóa URL cũ, dán đoạn javascript:… → Lưu (đặt tên: Story Reader).
  5. Mở trang chương truyện → mở bookmark Story Reader.

Chrome Android: gõ tên bookmark trên thanh địa chỉ rồi chọn bookmark (mở từ màn hình bookmark đôi khi thoát trang → script không chạy).

Giới hạn (so với extension máy tính)
  • Một số site (CSP chặt) chặn tải script từ ngoài → bookmark không chạy.
  • OCR / dịch chữ trong ảnh truyện tranh: chỉ bản extension.
  • Google TTS qua server extension: trên ĐT dùng giọng máy (Web Speech).
  • Mỗi lần mở trang mới / đổi chương: cần bấm lại bookmark (không tự inject).

3. Bật GitHub Pages (bắt buộc 1 lần)

Link https://vztong.github.io/story-reader-extension/ hiện 404 nếu chưa bật Pages.

  1. Repo → Settings → Pages
  2. Source: Deploy from a branch
  3. Branch: main · Folder: /docs → Save
  4. Đợi 1–2 phút, F5 trang này

File cần có trên branch: docs/index.html, docs/loader.js, docs/shim.js. Script chính vẫn lấy từ repo (content-scripts/, ui/) qua Pages hoặc jsDelivr.

Extension máy tính (đầy đủ tính năng)

GitHub repo → Load unpacked trên Chrome desktop.
